# 文科与创意类作业工作流

本参考文件只补充文科、社会科学和创意写作任务。理工科、代码、实验、定量分析和硬件任务继续执行 `SKILL.md` 的既有流程，不得因本文件而改写或弱化。

## 一 先判定作业类型

根据任务动词、课程专业、主要证据和交付物判断：

- 解释、比较、批评、史料论证、政策分析、田野或文本分析，通常属于文科或社会科学；
- 剧本、故事、演讲、策展文案、人物小传等以叙事和受众反应为核心的任务，属于创意写作；
- 同时包含程序、实验或定量模型与人文论证的任务，属于混合型，按章节或制品分别执行对应分支。

把类型判断、适用分支和边界写进范围锁。判断改变时，说明原因并同步评分标准，不追溯性篡改已经核验的证据。

## 二 建立来源池而不是先写结论

当文科任务需要外部调研时，在正式定稿前建立不少于 50 条相关候选材料的来源池；任务书禁止外部资料、范围极窄或用户明确要求只用指定材料时，以更高优先级要求为准。来源池是研究过程，不等于参考文献表，也不要求把 50 条全部引用进正文。

候选材料可包括：

- 官方档案、法规、统计、机构出版物和权威数据库；
- 同行评审论文、学术专著、学位论文和高质量综述；
- 可靠媒体的深度报道、公开演讲、访谈和口述史；
- 具有显著传播度、公共讨论度或代表性的作品与案例；
- 能呈现真实人物处境、情感经验或利益关系的一手材料。

每条候选材料至少记录标题、作者或机构、年份、链接或稳定标识、材料类型、与任务的关系，并按以下维度标记：权威性、相关性、传播或代表性、情感或叙事价值、利益相关性、可核验性、偏见与局限。

材料进入来源池应至少在权威性、公共影响、情感或代表性、利益相关性中有一项突出，同时满足基本相关性。热度、感人或利益相关只能说明“值得研究”，不能替代事实可靠性；关键事实仍需用官方材料、原始资料或可靠学术来源交叉核验。

先广泛检索，再分层精读：

1. 浏览不少于 50 条候选材料并去重；
2. 依据任务问题筛出高相关核心来源；
3. 对承担关键事实、核心概念、主要人物或因果判断的来源阅读全文或完整相关章节；
4. 用至少两个独立可靠来源核验关键事实，无法交叉核验时明确限定或不使用；
5. 正文只引用真正支撑论证或创作选择的材料，不为达到数量堆砌引用。

## 三 借鉴方法不复制表达

研究优秀作品时，分别记录可以迁移的方法：

- 它从什么问题或利益冲突出发；
- 它如何选择叙述视角、人物关系和信息顺序；
- 它如何把史料、概念或案例转化为论证或情节；
- 它如何安排悬念、转折、沉默、象征、节奏和情绪释放；
- 它怎样处理不同群体的利益、代价、责任和声音；
- 它的结论或情感效果依赖哪些可验证前提。

可以借用问题意识、研究方法、论证逻辑、利益分析框架和抽象叙事技巧；不得复制独特措辞、段落、场景、人物组合、情节链、标志性意象或可识别结构。完成初稿后检查与核心参考作品的表达和结构相似性，重写过近部分，并保留来源与创作选择的可追溯记录。

## 四 没有细化 rubric 时自建评分标准

若只有主题、资格、格式或笼统评价词，没有分值分布，建立一份内部评分表用于迭代，但不得把它冒充官方评分标准。权重按以下顺序确定：

1. 任务书明确强调的目标；
2. 用户为本任务指定的目标与权重；
3. 课程学习目标和交付物功能；
4. 该文类的必要质量门槛。

评分维度可从主题契合、事实与史料可靠性、观点或立意、人物与利益冲突、结构与逻辑、原创性、情感与受众效果、语言与文体、格式与提交合规中选择。只保留能改变作品质量或合规性的维度，总分保持 100，并为每项写出可观察的高档描述和证据位置。

不存在适用于所有文科作业的固定权重。只有任务书或用户对当前任务明确指定时，才把“感染力”“感人程度”或其他单项设为特定比例；不得把某次任务的 40% 等权重迁移到其他作业。

自建评分表属于 `Quality improvement`，除非能逐项追溯到官方要求。每轮先处理会导致失格、事实错误、抄袭、主题偏离或主要论证崩塌的问题，再处理结构、情感和语言。

## 五 文科证据与写作闭环

对分析性作业，使用以下链条：

```text
问题 → 论点 → 来源或文本证据 → 解释 → 反证或替代解释
→ 利益与立场 → 边界和局限 → 回答问题
```

对创意写作，使用以下链条：

```text
主题与受众 → 史料或现实基底 → 人物欲望与利益冲突
→ 场景行动 → 情绪曲线 → 价值选择与代价
→ 事实和伦理复核 → 受众试读 → 重写
```

感人不能只靠口号、苦难堆叠或旁白解释。优先用人物的具体目标、克制的细节、可见行动、关系变化、真实代价和有准备的情绪释放产生效果。涉及真实人物、创伤、战争、民族、性别、疾病或弱势群体时，避免消费苦难、篡改关键事实或把复杂群体工具化。

## 六 迭代与验收

每轮至少产生一种可检查结果：来源矩阵、提纲、论证图、人物关系、场景表、完整初稿、试读反馈或修订稿。不得只做语言润色。

最终至少检查：

- 类型判断与任务要求是否一致；
- 候选来源池数量、去重、来源层级和关键事实交叉核验；
- 每个关键论点、史实和创作选择是否能追溯；
- 是否只借鉴方法而未复制表达或可识别结构；
- 自建评分表是否明确标注为内部标准，权重是否来自当前任务；
- 作品是否同时通过事实、逻辑、原创性、伦理、受众效果、格式和提交门禁；
- AI 使用说明是否真实，作者需要亲自确认的经历、感受和创作决定是否仍由作者负责。
